# FP&A Analyst Skill

## Overview

Provides financial planning and analysis frameworks for annual operating plans, rolling forecasts, variance analysis, and business performance reporting. Bridges the gap between financial numbers and business narrative to drive operational performance and resource allocation decisions.

## Capabilities

### Annual Operating Plan (AOP)

**Planning Cycle (Q4 for following year)**
```
Week 1-2:  Strategic Alignment — leadership meetings, define financial targets
Week 2-3:  Top-Down Targets — revenue and profitability targets with CFO/CEO
Week 3-6:  Bottom-Up Build — partner with department heads on expense and headcount
Week 6-7:  Gap Reconciliation — bridge top-down targets and bottom-up builds
Week 7-8:  Scenario Development — upside, downside, stress test scenarios
Week 8-9:  Board Presentation — prepare and present operating plan
Week 9-10: Budget Load — load approved budgets into planning systems
```

### Monthly Business Review (MBR)

**Monthly Operating Rhythm**
```
Day 1-3:   Pull actuals from accounting (post-close), pull operational KPIs
Day 3-5:   Build variance analysis — revenue, expense, headcount, KPIs
Day 5-7:   Meet with department heads to review variances, confirm forward outlook
Day 7-8:   Update rolling forecast based on latest information
Day 8-10:  Prepare MBR package and present to leadership
Day 10:    Distribute finalized MBR, archive documentation
```

### Rolling Forecast Framework

**Quarterly Re-Forecast Process**
1. Reassess full-year outlook based on YTD performance and pipeline/bookings data
2. Incorporate changes in headcount timing, project delays, market conditions
3. Update scenario ranges and stress test the revised forecast
4. Present re-forecast to leadership with clear bridge from prior forecast

**Forecast Accuracy Tracking**
```
Forecast Accuracy = 1 - |Forecast - Actual| / |Actual|
Target: ≥95% accuracy on revenue, ≥92% on EBITDA
Track by: metric, time horizon (30/60/90 day), department
Root cause analysis required for any miss >5%
```

### Driver-Based Forecasting Models

**SaaS Revenue Model Drivers**
```
ARR = Beginning ARR + New Bookings - Churn + Expansion
MRR = ARR / 12
Revenue (recognized) = function of billing terms and deferred revenue movement

Key rates to track:
- Net Revenue Retention (NRR): (Beginning ARR + Expansion - Contraction - Churn) / Beginning ARR
- Gross Revenue Retention (GRR): (Beginning ARR - Contraction - Churn) / Beginning ARR
- CAC Payback: CAC / (ACV × Gross Margin)
```

**Headcount Cost Model**
```
Fully-loaded cost per FTE = salary + benefits (20-25%) + equity (varies) + tools/software + office/overhead allocation
Timing: account for ramp month (50% productivity assumption for new hires)
Attrition: build in expected turnover (typically 15-20% per year for tech)
```

## Scripts

### `scripts/variance_analyzer.py`

Automates budget-vs-actual variance analysis with root cause decomposition and forward impact assessment.

```
Usage: python variance_analyzer.py actuals.csv budget.csv [--prior-month prior.csv] [--threshold 5000] [--format json|table]
Input: CSV files for actuals, budget, and optional prior month with columns:
       department, category, amount
Output:
  - Variance table by department and category
  - Dollar and percentage variance columns
  - Flagged items above threshold
  - YTD cumulative variance summary
  - Forecast impact note (timing vs. permanent miss)
```

### `scripts/forecast_accuracy_tracker.py`

Tracks rolling forecast accuracy over time and identifies systematic biases by department or metric.

```
Usage: python forecast_accuracy_tracker.py history.csv [--periods 6] [--format json|table]
Input: CSV with columns: period, metric, department, forecast_30d, forecast_60d, forecast_90d, actual
Output:
  - Accuracy by forecast horizon (30/60/90 days)
  - Accuracy by department and metric
  - Bias detection (consistently high/low)
  - Trending accuracy chart data
```

### `scripts/headcount_cost_modeler.py`

Models fully-loaded headcount costs with timing, ramp assumptions, and attrition.

```
Usage: python headcount_cost_modeler.py hc_plan.csv [--benefits-pct 0.22] [--ramp-months 3] [--attrition 0.18]
Input: CSV with columns: department, role, start_month, base_salary, equity_annual
Output:
  - Monthly fully-loaded cost by department
  - Total headcount trajectory (beginning, hires, attrition, ending)
  - Variance between plan and run-rate cost
  - Productivity-adjusted cost (accounting for ramp)
```

### `scripts/saas_metrics_calculator.py`

Calculates core SaaS metrics from booking and billing data.

```
Usage: python saas_metrics_calculator.py arr_data.csv [--format json|table]
Input: CSV with beginning ARR, new bookings, expansion, contraction, churn by month and cohort
Output:
  - ARR waterfall (new + expansion - contraction - churn)
  - NRR and GRR by cohort and in aggregate
  - CAC payback period by segment
  - LTV/CAC ratio
  - Rule of 40 (revenue growth % + FCF margin %)
```

## Quality Standards

- Annual operating plan delivered and approved by board on schedule
- Quarterly forecast accuracy within ±5% of actuals for revenue, ±8% for EBITDA
- Monthly business review delivered within 10 business days of month-end (target: 7 days)
- 100% of budget owners receive variance reports with actionable insights each month
- Rolling forecast maintained with < 2-week lag to current period
- Variance explanations resolve 95%+ of total variance to specific drivers
